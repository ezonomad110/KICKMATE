# KICKMATE（サッカー将棋）

将棋のように1手ずつ選手を動かす、ターン制のサッカーゲーム。9列×13行の盤面で11人制、運要素なしの完全実力勝負。

▶ **プレイはこちら**: https://ezonomad110.github.io/KICKMATE/

## 遊び方（要点）

- 1ターンに1選手が1行動（移動かキック）。制限は役割と方向で決まる
- パスが味方に通る・ボールを奪う・ルーズボールを拾うと、続けてその選手がもう1手行動できる
- 奪取は保持者の縦横1マスから無条件。ただし奪った選手はそのターン直接ゴール不可
- キックは直線5マスまで。直接ゴールに入れられるのは3マスまで。FWは斜め後ろに蹴れない
- オフサイドあり。GKはターンに1回、ゴール前エリア内で1マス無料で動ける
- 全100手で試合終了、得点の多い方が勝ち

## モード

- 🤖 CPU対戦（通常）
- 👹 CPU上級（全候補手を評価して最善手を選ぶ強敵）
- 👥 2人対戦（同じ画面で交互に操作）

## ファイル

- `index.html` — ゲーム本体（UI）
- `logic.js` — ルールとCPUのロジック
- `tests/logic.test.js` — ロジックのテスト（`node tests/logic.test.js`）
